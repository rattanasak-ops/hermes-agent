## การคัดงาน NCR

รับไว้เป็นผู้สมัครแก้หลังสัญญา Portal ชัด:

- ต่ออายุ writer lease ของ task/worktree เดิมได้เมื่อผู้เขียน เครื่อง branch และ Git ตรงทั้งหมด
- `hermes-new-chat status` ต้องปฏิเสธ permit ที่หมดอายุ แม้ WTL ยังพร้อม
- Relay ต้องไม่นับงานเขียนว่าสำเร็จถ้า workspace ไม่เปลี่ยน
- รอบรีวิวต้องมีคำตัดสิน `PASS` หรือ `FIX_REQUIRED`
- การยกเลิกต้องฆ่ากลุ่มกระบวนการลูกและล้างสถานะค้าง

ตัดออก:

- local fallback อัตโนมัติเมื่อ Portal token ขาด
- prompt/payload รุ่นเก่าที่ `main` มีรุ่นใหม่กว่าแล้ว
- ชุดติดตั้ง New Chat ซ้ำอีกตำแหน่งหนึ่ง
- commit NCR สองตัวที่ `git cherry` ยืนยันว่า `main` มีเนื้อหาเท่ากันแล้ว
