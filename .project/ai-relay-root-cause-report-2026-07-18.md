1. Codex ตรงตอบงานสั้นได้ประมาณ 16.54 วินาที จึงยังไม่มีหลักฐานว่า Codex เสีย
2. การที่ Relay รายงานว่าไม่พบ Portal token ไม่ได้แปลว่า AI Portal ไม่มีบัญชี; แปลว่าโปรแกรมบนเครื่องไม่พบกุญแจที่มันรู้จัก
3. ข้อความ Grok `API key required` มาจากการไหลไป CLI ในเครื่อง จึงไม่ใช่หลักฐานว่าบัญชี Grok ใน Portal ไม่มี

5. ยังไม่มีการเดินเส้นจริงหลังแก้ จึงห้ามกล่าวว่าระบบใช้งานได้ครบ

## 5. สัญญากลางที่ต้องสร้างก่อนแก้ Relay

AI Portal ต้องเป็นผู้ตัดสินเพียงจุดเดียวตามลำดับนี้:

```text
Cursor / Claude Code App / Codex App
  → ส่งกุญแจผู้ใช้ + โปรแกรมต้นทาง + โมเดลที่ขอ + Codex ID ที่กำลังล็อกอิน
  → AI Portal ตรวจผู้ใช้ บทบาท โมเดล งบ และบัญชีที่อนุญาต
  → AI Portal เลือกบัญชีทำงาน (Codex: 01 ใช้ 02, 02 ใช้ 01)
  → ส่งข้อมูลความคืบหน้าและผลลัพธ์กลับ
```

กฎบังคับ:

- Relay ห้ามเปลี่ยนไป CLI ในเครื่องเมื่อ Portal ใช้ไม่ได้
- Relay ห้ามเปลี่ยนไป AI ตัวอื่นเมื่อเจ้าของระบุชื่อชัด
- `fable` ต้องเป็นชื่อที่ Relay รู้จักและส่งให้ Portal ตัดสินสิทธิ์
- ถ้าไม่มีสิทธิ์ ให้คืน `permission_denied`; ถ้าโมเดลยังไม่เปิด ให้คืน `model_unavailable`
- เหตุเชื่อมต่อ Grok ชั่วคราวต้องแยกจาก auth และมีขอบเขตลองซ้ำที่ตั้งค่าได้
- stdout เก็บ JSON สุดท้าย; ความคืบหน้าออก stderr โดยไม่เผย prompt หรือกุญแจ

## 6. งานแก้ฝั่ง Hermes Agent

1. เปลี่ยน `DEFAULT_ADAPTERS` ให้ทุก AI ที่เปิดใช้ รวม Fable เรียก `relay-portal` เท่านั้น
2. ลบการเปลี่ยนไป CLI ในเครื่องจากทางปกติ; โหมดทดสอบเฉพาะเครื่องต้องปิดเป็นค่าปริยายและเปิดได้ด้วยคำสั่งเจ้าของเท่านั้น
3. เพิ่มข้อมูล `client`, `user/session`, `requested_model` และ `active_codex_login_slot` ในสัญญา Relay→Portal โดยไม่ส่งข้อมูลลับลงบันทึก
4. ให้ Portal เป็นผู้คืนบัญชีที่เลือกจริง; Relay จดเพียงรหัสอ้างอิงที่บังข้อมูลแล้ว
5. ส่งข้อมูลระหว่างทำงานและ heartbeat ทาง stderr พร้อมเวลาที่ผ่านไปและเวลาข้อมูลล่าสุด
6. แยก startup timeout, silence timeout และ total timeout พร้อมตรวจว่ากระบวนการลูกยังอยู่
7. ครอบคำสั่งหลักด้วย `try/finally`; ล้าง `now.json`, ปิด lock และฆ่ากระบวนการลูกทุกทางออก
8. แยก `auth`, `permission_denied`, `model_unavailable`, `connection_lost`, `quota`, `timeout` และ `cancelled` ให้ชัด
9. ติดตั้งจาก source ด้วย `install-local.sh` และยืนยันว่าไฟล์ติดตั้งตรงกับ source

## 7. งานที่ต้องเกิดฝั่ง AI Portal ก่อนเดินเส้นจริง

1. เพิ่มทะเบียนโมเดล Fable และผูกบัญชีที่เรียกได้จริง
2. เพิ่มสิทธิ์ระดับผู้ใช้และบทบาท โดย Portal เป็นจุดตรวจเดียวทุกช่องทาง
3. เพิ่มกฎ Codex cross-route 01↔02 ฝั่ง Portal พร้อมหลักฐานบัญชีที่ถูกเลือก
4. เพิ่มการตรวจสุขภาพ Grok การต่ออายุสิทธิ์ การลองซ้ำ และการบอกเหตุเชื่อมต่อหลุด
5. ส่งข้อมูลแบบต่อเนื่องให้ Relay และทั้ง 3 โปรแกรมรับความคืบหน้าได้
