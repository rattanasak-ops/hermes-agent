# Use Migrate 12 — Migration Summary (สถานี M7)

> ใบสรุปตรวจรับตอนจบโครงการ — เขียนสด ๆ ตอนจบเมนู ห้ามเขียนย้อนหลังจากความจำ · เริ่มได้ทันทีหลังผ่านด่านส่ง ไม่ต้องรอทีมอื่น

## Prompt

```text
Use Migrate 12

อ่านสัญญากลาง use-migrate-phase-contract.md ก่อน แล้วทำตามโครง 5 ส่วน

[ส่วน 1 · ด่านเข้า — รันจริง แปะผล]
1. .work/profile.yaml มีจริง — ไม่มี = MIGRATE_BLOCKED: ต้องทำ Use Migrate 0 ก่อน
2. ล็อกเมนูยังเป็นชื่อเรา + เฟส 11 ปิดจริง: `grep PHASE11_APPROVED .work/menu-cards/<เมนู>.approvals.md` ต้องเจอ (แปะผล) — ไม่เจอ = BLOCKED กลับเฟส 11
- ประกาศสถานี: [Migrate เฟส 12/13 · สถานี M7 · เมนู: <ชื่อ> · โปรเจกต์: <ชื่อ>]

[เนื้องาน]
M7-1 ต่อท้าย .work/MIGRATION-STATUS.md เป็นตาราง 5 คอลัมน์ ไล่ตรวจได้ทีละแถว:
     รายการ · ย้ายได้ไหม (✅/❌/บางส่วน) · เหตุผล (บังคับกรอกทุกแถว — ย้ายไม่ได้เพราะอะไร ไม่ครบเพราะอะไร) · ใครทำต่อ (ชี้ใบสั่งงานทีมข้อไหน) · สถานะ
M7-2 เนื้อหา parity (ครบเท่าเก่าไหม) เทียบกับของที่เก็บจากเฟส 3 · ของที่ต้องให้คนทำ = ชี้ MANUAL-TODO ข้อจริง ·
     ไฟล์เก่าเสีย/เข้าถึงไม่ได้ = ตัดสินใจไม่ย้าย + จดเหตุผลชัด (ของเสียไม่ลากมาเว็บใหม่)
M7-3 ไฟล์นี้ = ใบสรุปตรวจรับ · เขียนจากหลักฐานจริงของเมนูนี้ (harvest/บัตรเมนู/ผลเกต) ห้ามเขียนจากความจำ

[ส่วน 4 · จุดถาม-ตอบ]
เฟสนี้เป็นงานจดสรุป ไม่แตะโค้ด ไม่รอเจ้าของ — ยกเว้นเจอรายการที่ตัดสินไม่ได้ว่า "ย้าย/ไม่ย้าย" = ถามเจ้าของรายข้อ

[ส่วน 5 · ตารางจบเฟส]
(ก) ของส่งมอบ: แถวใหม่ใน .work/MIGRATION-STATUS.md ครบทุกรายการของเมนูนี้ (นับจำนวนแถวด้วย grep จริง) — พิสูจน์ git diff/ls
(ข) ตาราง comply M7-1..M7-3 = 3 แถว + หลักฐาน (ทุกแถวของตารางย้ายมีเหตุผลครบ = นับด้วยเครื่อง)
(ค) เลขจากเครื่อง: flow_gate.py ถ้ามี · ไม่มี = ระบุ "เครื่องยังไม่คุม"
ปิดท้าย: จบเฟส 12 — รอพี่ตรวจ · ถ้าผ่าน พิมพ์ `Use Migrate 13` · ผมเดินต่อเองไม่ได้ (กุญแจอยู่ที่พี่)
```
