# Use Migrate 7 — Wow Design ใส่ชั้นอารมณ์ (สถานี M3.5)

> จุดอนุมัติสี/ฟอนต์/token ใหม่อยู่ที่นี่ **ก่อนเขียนโค้ด** — M8 เป็นแค่จุดบันทึก · ห้ามคิดใหม่กลางทางตอนโค้ด

## Prompt

```text
Use Migrate 7

อ่านสัญญากลาง use-migrate-phase-contract.md ก่อน แล้วทำตามโครง 5 ส่วน

[ส่วน 1 · ด่านเข้า — รันจริง แปะผล]
1. .work/profile.yaml มีจริง — ไม่มี = MIGRATE_BLOCKED: ต้องทำ Use Migrate 0 ก่อน
2. ล็อกเมนูยังเป็นชื่อเรา + asset-register ปิดแล้ว (เจ้าของเลือกภาพครบจากเฟส 6) — ไม่ครบ = BLOCKED กลับเฟส 6
- ประกาศสถานี: [Migrate เฟส 7/13 · สถานี M3.5 · เมนู: <ชื่อ> · โปรเจกต์: <ชื่อ>]

[เนื้องาน]
M3.5-1 เลือกอารมณ์เมนูนี้ — archetype (12 แบบ) + คะแนน 5 แกน (ทางการ/อบอุ่น/พลัง/หรู/สนุก) → ทิศทาง token (สี/มุมโค้ง/motion/gradient)
M3.5-2 ออกแบบลูกเล่น/การเคลื่อนไหว (นับถอยหลัง/counter/hover/scroll) เข้ากับอารมณ์ + เคารพ prefers-reduced-motion
       เกณฑ์พอดี: ทุกหน้าต้องมี ≥1 ลูกเล่นที่มีความหมาย (เล่าเรื่อง/นำสายตา/ตอบสนองการกด) · ห้ามใส่จนแย่งเนื้อหา · ต้องไม่ฉุดคะแนนความเร็ว
M3.5-3 ภาพประกอบเพิ่มเติม: ตามกฎภาพ 2 ชั้น DEC-167 · ยังห้ามคน/ใบหน้า/มือเด็ดขาด · ผ่านมือกราฟิก · เจ้าของอนุมัติทุกภาพ
M3.5-3b UX การนำทาง: ระบุจุดเด่นอันดับ 1 ที่ตาต้องเห็นก่อน (1 อย่างเท่านั้น) + วาดทางเดินสายตา 1-2-3 ลงแบบ · เมนู/dropdown เน้นรายการสำคัญ
M3.5-3c จุดเสนอสี/ฟอนต์/token ใหม่ (ต้องอนุมัติก่อนเขียนโค้ด): ระบบดีไซน์ขาดเฉด/ฟอนต์/องค์ประกอบที่งานนี้ต้องใช้ → เสนอเจ้าของอนุมัติที่นี่ ก่อนเข้าเฟส 8
M3.5-4 เขียนแผน Wow ลง brief (หัวข้อ Wow Design) → เจ้าของเห็นก่อน แล้วค่อยเฟส 8
M3.5-5 ผ่านเมื่อ: brief มีอารมณ์+ลูกเล่น+ภาพที่อนุมัติ + token ใหม่ (ถ้ามี) อนุมัติแล้ว · ไม่มี = เข้าเฟส 8 ไม่ได้

เสนอ layout จากคลังกลาง (กติกาเดิม): มีผ่านเกณฑ์กี่ตัวโชว์เท่านั้น ห้ามแต่งเพิ่มให้ครบ · ทุกตัวเลือกจด layout_id + สถานะ (โค้ดจริง/สูตร) + เหตุผล ·
เจ้าของไม่ชอบ = เปลี่ยนจากคลัง + แจ้งผลกระทบ · เปลี่ยนหลังเฟสนี้ = ย้อนตรวจ REQ/เทสต์/เอกสารที่กระทบ ห้ามสลับเงียบ

[ส่วน 4 · ชุดคำถามบังคับ — รอบเดียว แล้วหยุดรอ]
ส่งแผนว้าว (อารมณ์+คะแนน 5 แกน+ลูกเล่น+จุดเด่นอันดับ 1+layout ที่เสนอ+ภาพเพิ่ม+token ใหม่ถ้ามี) แล้วถาม:
1. แผนว้าวนี้ เอาไหม ปรับตรงไหน?
2. layout ที่เสนอจากคลัง — เลือกตัวไหน?
3. token/สี/ฟอนต์ใหม่ (ถ้ามี) — อนุมัติไหม? (ไม่อนุมัติ = ใช้ของเดิมเท่านั้น)
→ คำตอบจดลง brief หัวข้อ Wow Design

[ส่วน 5 · ตารางจบเฟส]
(ก) ของส่งมอบ (ล็อก path ชัด): หัวข้อ `## Wow Design` ใน .work/menu-cards/<เมนู>.brief.md (อารมณ์/ลูกเล่น/layout_id/token ที่อนุมัติ) + ป้าย `WOW_APPROVED` และ `TOKEN_APPROVED` (ถ้ามี token ใหม่) ใน .work/menu-cards/<เมนู>.approvals.md — พิสูจน์ grep ทั้งสองไฟล์
(ข) ตาราง comply M3.5-1..5 + 3b + 3c + layout = 8 แถว + หลักฐาน
(ค) เลขจากเครื่อง: flow_gate.py ถ้ามี · ไม่มี = ระบุ "เครื่องยังไม่คุม"
ปิดท้าย: จบเฟส 7 — รอพี่ตรวจ · ถ้าผ่าน พิมพ์ `Use Migrate 8` · ผมเดินต่อเองไม่ได้ (กุญแจอยู่ที่พี่)

[ข้อห้ามเฉพาะเฟสนี้]
- ห้ามแตะโค้ดหน้า (เฟส 8) — token ที่ยังไม่อนุมัติ = ไม่มีอยู่จริงสำหรับงานนี้
```
