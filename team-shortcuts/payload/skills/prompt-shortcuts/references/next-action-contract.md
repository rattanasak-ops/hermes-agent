# สัญญาขั้นตอนถัดไป

กฎนี้ใช้กับ Shortcut ทุกตัว เมื่อคำตอบเป็นการสรุปผล รายงานสถานะ รายงานข้อขัดข้อง ส่งต่องาน หรือกล่าวว่าปิดงาน ต้องเรียงข้อมูลสำหรับเจ้าของก่อนข้อมูลของระบบตามแบบนี้:

````markdown
## สรุปภาษาคน

ไม่เกิน 5 บรรทัด บอกว่าทำอะไรแล้ว เหลืออะไร และส่งผลอย่างไร

## สรุป Phase

| Phase | สถานะ N/M | % | แปลเป็นภาษาคน |
|---|---:|---:|---|
| <ชื่อ Phase> | <N/M> | <X%> | <เจ้าของอ่านแล้วเข้าใจผล> |

## งานต่อไปคืออะไร

- งานเดียวที่ควรทำต่อ

## Prompt ที่ควรใช้ต่อ

```text
ข้อความพร้อมคัดลอก เมื่อเจ้าของต้องเปิดหรือส่งต่อแชท
```
````

ถ้า AI ทำต่อเองได้ ไม่ต้องสร้าง Prompt ส่งต่อ ให้เขียนในหัวข้อ `งานต่อไปคืออะไร` แล้วลงมือในรอบเดิม ส่วนหัวข้อด้านล่างมีไว้เก็บข้อมูลให้ระบบอ่าน แต่ห้ามใช้แทนสรุป Phase และงานถัดไป:

```markdown
สถานะ: ผ่าน N/M = X% · ค้าง N/M = Y%

## ขั้นตอนถัดไป

- ผู้ทำต่อ: AI / เจ้าของ / ระบบภายนอก
- ขั้นถัดไป: การกระทำที่ชัดเจนหนึ่งก้อน
- เริ่มเมื่อ: ทำทันที หรือเงื่อนไขที่ต้องเกิดก่อน
- หลักฐานปิดด่าน: ผล N/M, คำสั่งตรวจ, ภาพจริง หรือคำรับรองที่ต้องพบ
- เจ้าของต้องทำตอนนี้: ไม่ต้องทำอะไร หรือการกระทำเดียวที่เล็กที่สุด
- เหตุผลที่หยุด: งานครบจริง / ต้องใช้สิทธิ์ / รอผลภายนอก / ติดกฎ พร้อมหลักฐาน
- กลับมาทำต่อที่: ต้องมีเมื่อผู้ทำต่อเป็นเจ้าของหรือระบบภายนอก
```

## กติกาบังคับ

1. ต้องขึ้นต้นส่วนรายงานด้วยหัวข้อ `สรุปภาษาคน` และมีเนื้อหาไม่เกิน 5 บรรทัด
2. ต้องมีตาราง Phase เสมอ โดยใช้หัวตาราง `Phase | สถานะ N/M | % | แปลเป็นภาษาคน`
3. ต้องมีหัวข้อ `งานต่อไปคืออะไร` และมีงานเดียวที่ชัดเจน
4. ถ้าเจ้าของต้องเปิดหรือส่งต่อแชท ต้องมีหัวข้อ `Prompt ที่ควรใช้ต่อ` พร้อมข้อความคัดลอกได้
5. ห้ามส่งเฉพาะ `ผู้ทำต่อ`, `เริ่มเมื่อ`, `กลับมาทำต่อที่` โดยไม่มีสรุป Phase และงานถัดไปแบบภาษาคน
6. ทุกบรรทัดที่ใช้คำว่า `เสร็จ`, `ผ่าน` หรือ `ค้าง` ต้องมีทั้ง N/M และเปอร์เซ็นต์ในบรรทัดเดียวกัน
7. ถ้างานในเครื่องจบ แต่ยังเหลือการรวม Git หรือระบบภายนอก ต้องใช้ประโยคนี้ตรงตัว: `งานในเครื่องจบแล้ว เหลือ merge/ระบบภายนอกที่ต้องได้รับอนุมัติหรือสิทธิ์เพิ่ม`
8. ถ้า AI ยังทำงานที่ปลอดภัยในขอบเขตที่อนุมัติได้ ให้ระบุงานถัดไปแล้วทำต่อในรอบเดียวกัน ห้ามให้เจ้าของพิมพ์ “ต่อ”
9. ถ้าต้องใช้เจ้าของหรือระบบภายนอก ให้ทำส่วนที่ AI ทำได้ให้ครบก่อน แล้วขอการกระทำเดียวที่เล็กที่สุด พร้อมระบุว่าจะกลับไปเดินงานตรงไหน
10. ถ้างานจบจริง ให้รายงานงานค้างเป็น 0/N และเขียน `ขั้นถัดไป: ไม่มี งานตามคำสั่งครบ N/N`
11. ห้ามรายงาน 100% เมื่อยังมีการอนุมัติเจ้าของ, Pull Request เปิด, การรวม Git, Tier 5, หลักฐานด่าน, `claimed` หรือ `owner-pending` ค้าง
12. ห้ามใช้ข้อความกว้าง ๆ เช่น “ตรวจเพิ่ม”, “รอเจ้าของ” หรือ “พร้อมทำต่อ” โดยไม่มีผู้ทำ การกระทำ เงื่อนไขเริ่ม หลักฐานปิดด่าน สิ่งที่เจ้าของต้องทำ และเหตุผลที่หยุด
13. คำตอบสนทนาทั่วไปที่ไม่ได้รายงานงานไม่ต้องเพิ่มหัวข้อนี้
14. ถ้าระบุ `ผู้ทำต่อ: AI`, `เริ่มเมื่อ: ทันที` และงานค้างมากกว่า 0 ด่านต้องบล็อกคำตอบและให้ AI กลับไปลงมือ ห้ามเพียงเขียนสรุปใหม่
15. สถานะของเครื่องมืออย่างเดียวไม่พอ ต้องบอกเป็นภาษาไทยว่าผลนั้นทำให้เจ้าของ ทีม หรือผู้ใช้ทำอะไรได้ดีขึ้นหรือปลอดภัยขึ้น

## ผลที่ต้องการ

- เจ้าของไม่ต้องถามว่า “แล้วทำอะไรต่อ”
- AI ไม่หยุดทั้งที่ยังมีงานปลอดภัยในเฟสเดิม
- งานที่รอเจ้าของเหลือเป็นคำขอเดียวที่ทำได้จริง
- คำว่าเสร็จและเปอร์เซ็นต์ตรงกับหลักฐาน
