# Use Migrate 2 — ด่านรับตัวอย่าง Benchmark (สถานี M0.5)

> กันเหตุ "ลอกตัวอย่าง 100%" · ทุกตัวอย่างที่เจ้าของส่งต้องถูกแตกส่วน-เลือก-แปลงเข้าระบบดีไซน์ของเราเสมอ

## Prompt

```text
Use Migrate 2

อ่านสัญญากลาง use-migrate-phase-contract.md ก่อน แล้วทำตามโครง 5 ส่วน

[ส่วน 1 · ด่านเข้า — รันจริง แปะผล]
1. .work/profile.yaml มีจริง — ไม่มี = MIGRATE_BLOCKED: ต้องทำ Use Migrate 0 ก่อน
2. ล็อกเมนูใน .work/menu-queue.md ยังเป็นชื่อเรา (pull ล่าสุดก่อนตรวจ)
3. ไฟล์เฟสก่อน: .work/menu-cards/<เมนู>.confirm.md มีคำตอบเจ้าของครบ — ไม่มี = BLOCKED กลับเฟส 1
- ประกาศสถานีทุกคำตอบ: [Migrate เฟส 2/13 · สถานี M0.5 · เมนู: <ชื่อ> · โปรเจกต์: <ชื่อ>]

[เนื้องาน — 2 ทางตามคำตอบเจ้าของจากเฟส 1]

ทาง ก · เจ้าของไม่มีตัวอย่างส่ง:
- สร้าง .work/menu-cards/<เมนู>.benchmark.md จดบรรทัด `status: NO_INPUT` + วันที่ + อ้างคำตอบเจ้าของจากเฟส 1 (คำต่อคำ) — มีร่องรอยเสมอ ไม่ใช่ข้ามเงียบ · ห้ามเขียน NO_INPUT เองโดยไม่มีคำตอบเจ้าของรองรับ
- แจ้งเจ้าของ 1 บรรทัดว่าจดแล้ว → ไปตารางจบเฟสได้เลย (เฟสนี้จบเร็วโดยชอบธรรม)

ทาง ข · เจ้าของส่งตัวอย่าง/benchmark มา (ลิงก์/ภาพ/ไฟล์):
- กฎเหล็ก: ห้าม copy 100% เด็ดขาด (โค้ด/ดีไซน์/asset)
1. วิเคราะห์แตกส่วน: ผัง layout / ลูกเล่น effect / script / โทนสี / โครงเนื้อหา — บอกว่าเด่นตรงไหน เพราะอะไร
2. ถามโจทย์กลับเจ้าของ: "ต้องการเอาส่วนไหนมาใช้" ให้เลือกเป็นข้อ (นี่คือชุดคำถามบังคับของเฟสนี้ — ถามรอบเดียว หยุดรอ)
3. ส่วนที่เจ้าของเลือก → แปลงเข้า Design System ของโปรเจกต์ (token ของเรา สีของเรา)
   + จดที่มาลง .work/benchmarks/<ชื่อตัวอย่าง>.md: มาจากไหน · เลือกส่วนไหน · แปลงยังไง
   + สร้าง .work/menu-cards/<เมนู>.benchmark.md จด `status: SELECTED` + รายการที่เจ้าของเลือก (คำต่อคำ) + ชี้ไฟล์ benchmarks/ — ไฟล์ benchmarks ว่างเปล่า/ไม่มีคำตอบเจ้าของ = ใช้ผ่านด่านไม่ได้

[ส่วน 5 · ตารางจบเฟส]
(ก) บัญชีของส่งมอบ (ตามทางที่เกิดจริง) — พิสูจน์ด้วย ls + git ls-files + cat เนื้อจริง:
  ทั้ง 2 ทาง: .work/menu-cards/<เมนู>.benchmark.md (status: NO_INPUT หรือ SELECTED + คำตอบเจ้าของ) · ทาง ข เพิ่ม: .work/benchmarks/<ชื่อ>.md เนื้อไม่ว่าง
(ข) ตาราง comply: ด่านเข้า 3 ข้อ + กติกาทาง ก/ข ที่ใช้ + หลักฐานต่อข้อ
(ค) เลขจากเครื่อง: มี flow_gate.py = แนบผล status · ไม่มี = ระบุ "เครื่องยังไม่คุม"
ปิดท้าย: จบเฟส 2 — รอพี่ตรวจ · ถ้าผ่าน พิมพ์ `Use Migrate 3` เพื่อไปต่อ · ผมเดินต่อเองไม่ได้ (กุญแจอยู่ที่พี่)

[ข้อห้ามเฉพาะเฟสนี้]
- ห้ามเริ่มเก็บเว็บเก่า/เขียนโจทย์/แตะโค้ด · เห็นว่าทำต่อได้ = จด "ของฝากเฟสถัดไป"
- ห้ามเอาสี/ฟอนต์/โค้ดจากตัวอย่างไปใช้ตรง ๆ โดยไม่ผ่านการแปลงเข้า token ของโปรเจกต์
```
