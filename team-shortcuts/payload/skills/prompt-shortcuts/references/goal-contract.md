# Goal Contract — ใบงานกัน AI เปลี่ยนเป้าหมาย

ไฟล์อำนาจมีเพียง `.project/active-task.json` หนึ่งชุด ส่วน `.project/active-task.md` เป็นมุมมองสำหรับคนที่สร้างจากไฟล์ JSON ห้ามใช้ plan เก่า ประวัติ แชท หรือไฟล์ parked ทับใบงานนี้

## ก่อนเริ่ม Shortcut ทุกตัว

1. เปิด `.project/active-task.json` แล้วตรวจด้วย `goal_contract.py --cwd <Git root> verify`
2. เทียบ `task_id`, `plan_id`, `goal_hash`, กิ่ง, SHA ฐาน, เส้นทางที่อนุญาต/ห้าม และชนิดงานกับงานที่จะทำ
3. ก่อนเขียนทุกครั้งให้ด่าน `enforce-goal-contract.py` ตรวจไฟล์จริง ถ้าระบุไฟล์ไม่ได้ให้หยุดด้วย `GOAL_PATH_UNRESOLVED`
4. ถ้า `status=frozen` ให้หยุดด้วย `BRANCH_FROZEN` งานใหม่ต้องมีใบงานใหม่ ห้ามคืนสถานะกิ่งเดิมเอง
5. คำว่า “อนุมัติ”, “ทำต่อ” หรือ “โอเค” เปลี่ยนขอบเขตไม่ได้ การเปลี่ยนต้องมีคำสั่ง `SCOPE CHANGE <งานเดิม> TO <งานใหม่>` พร้อมกิ่ง เส้นทาง และผลกระทบ
6. โปรเจกต์ผู้ใช้ Shortcut รายงานเหตุได้ แต่ห้ามแก้ Prompt, Shortcut หรือ Hook กลาง ให้ใช้ `hermes shortcut-incident record`; เหตุเดิมครั้งที่ 4 สร้าง Prompt ไปแก้ใน Hermes Agent

## ถ้ายังไม่มีใบงาน

- งานอ่านและวางแผนทำได้ แต่ห้ามเริ่มเขียนงานส่งมอบ
- ให้เรียก `Use Agent` เป็นทางเข้าหลักเพื่อวินิจฉัยเป้าหมายและสร้างข้อเสนอใบงาน
- หลังเจ้าของอนุมัติแผน/สเปคที่ระบุขอบเขต จึงสร้างใบงาน active หนึ่งชุด
- ห้ามสร้าง Worktree หรือกิ่งเพื่อแก้การไม่มีใบงาน

## การทำงานทั้ง Phase

- `ZONE_A` ในกิ่งและเส้นทางเดิม: ทำต่อจนจบ Phase งบคำถามย่อย 0 ครั้ง
- `ZONE_B`: รวมขอเจ้าของครั้งเดียวต่อ Phase พร้อมผลกระทบและหลักฐานจากเครื่อง
- คำถามแทรกไม่ยกเลิก Phase; ก่อนกลับมาทำต่อให้ตรวจ `goal_hash` อีกครั้ง
- งานสนับสนุน เช่น Hook เอกสาร และชุดตรวจ ต้องแยกจากผลงานหลัก และห้ามเพิ่มเปอร์เซ็นต์ผลงานหลัก

## ก่อน commit, push, CI และ merge

- ก่อน commit/push ให้ด่านก่อนเขียนตรวจไฟล์เปลี่ยนทั้งหมด ไม่ใช่เฉพาะไฟล์ที่ AI ตั้งใจแตะ
- ใน CI/ก่อน merge ให้รัน `goal_contract.py --cwd <Git root> check-git --branch <branch> --base-sha <base_sha> --head-sha <head_sha>`
- ต้องผ่าน `GOAL_GIT_GATE_OK`; ด่านจำนวน commit/ไฟล์ของ Save Git ยังมีผลแยกต่างหาก ห้ามใช้ด่านใดด่านหนึ่งแทนอีกด่าน

## New Chat และ Close Chat

- ใบรับรองปิดแชทต้องมี `task_id`, `plan_id`, `goal_hash` ตรงใบงานปัจจุบัน
- แฮชไฟล์ตรงแต่ `goal_hash` ต่าง ให้หยุดด้วย `PROJECT_GOAL_DRIFT` ห้ามเขียนทับเพื่อทำให้ดูตรง
- งานถัดไปต้องมีเพียงหนึ่งข้อและต้องคัดจาก `next_prompt` ในใบงาน

## รูปแบบบรรทัดสุดท้ายของ Shortcut

ทุก Shortcut ต้องคืนหนึ่งในสองแบบนี้ ห้ามให้เจ้าของเดาชื่อคำสั่งถัดไป:

```text
Prompt ถัดไป: <ข้อความพร้อมคัดลอกหนึ่งบรรทัด>
```

หรือเมื่อ AI ยังทำงานปลอดภัยต่อได้:

```text
AUTO_CONTINUE: AI ทำ <phase/issue ถัดไป> ต่อเอง เจ้าของไม่ต้องพิมพ์อะไร
```
