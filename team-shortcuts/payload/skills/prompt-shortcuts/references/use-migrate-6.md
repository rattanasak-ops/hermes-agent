# Use Migrate 6 — จัดหาภาพ + เจ้าของเลือกทุกภาพ (สถานี M3)

> AI ห้ามสร้างภาพคน/ใบหน้า/มือ/ภาพถ่ายเสมือนจริงเด็ดขาด · เจ้าของเลือกทุกภาพ · เพดานไฟล์เช็กที่ต้นทางด้วยคำสั่งจริง — ไม่ใช่ไปเจอ 800KB ตอนด่านมาตรฐานแล้วรื้อ

## Prompt

```text
Use Migrate 6

อ่านสัญญากลาง use-migrate-phase-contract.md ก่อน แล้วทำตามโครง 5 ส่วน

[ส่วน 1 · ด่านเข้า — รันจริง แปะผล]
1. .work/profile.yaml มีจริง — ไม่มี = MIGRATE_BLOCKED: ต้องทำ Use Migrate 0 ก่อน
2. ล็อกเมนูยังเป็นชื่อเรา + image-direction.md ปิดแล้ว (คำตอบเจ้าของครบ) — ไม่มี = BLOCKED กลับเฟส 5
3. PRE-IMAGE GATE ก่อนแตะเครื่องมือภาพทุกครั้ง (เช็กซ้ำเสมอ แม้เคยตอบล่วงหน้าตั้งแต่เฟส 1):
   มีคน/ใบหน้า/มือ? → หยุดเด็ดขาด (คนจัดหาเท่านั้น) · ภาพประกอบไม่มีคน? → กฎ 2 ชั้น DEC-167 · ไอคอน/เวกเตอร์? → เจ้าของอนุมัติแล้วหรือยัง
- ประกาศสถานี: [Migrate เฟส 6/13 · สถานี M3 · เมนู: <ชื่อ> · โปรเจกต์: <ชื่อ>]

[เนื้องาน — กฎภาพครบชุด]
M3-1 AI ทำแค่: เขียน brief ต่อภาพ + ค้น/เสนอลิงก์ stock ลิขสิทธิ์จริง (คนไทย/เอเชีย) ให้เจ้าของเลือก
M3-2 กฎภาพ 2 ชั้น (DEC-167): ชั้น 1 ภาพคน/ใบหน้า/มือ/ภาพถ่ายเสมือนจริง = คนจัดหาเท่านั้น ห้าม AI เด็ดขาด ·
     ชั้น 2 ภาพประกอบ/บรรยากาศ/นามธรรม/ฉากไม่มีคน = AI สร้างได้ แต่ต้องผ่านมือกราฟิกตกแต่ง (ห้ามใช้ภาพ AI ดิบ) + ติดป้ายที่มา + เจ้าของอนุมัติรายภาพ
M3-3 ไอคอน/UI เวกเตอร์ล้วน → ทำได้เมื่อเจ้าของอนุมัติ (ผ่าน PRE-IMAGE GATE)
M3-4 เจ้าของเลือกทุกภาพ (จากใบเสนอภาพ 5 ช่องต่อภาพ: section/Emotion/Pain Point/ความคาดหวัง/Value+Wow)
M3-5 ทุกภาพลง .work/asset-register.md: ไฟล์ · ที่มา+URL stock+เลขลิขสิทธิ์ · ใครอนุมัติ+วันที่ · reviewer · + 2 คอลัมน์ keyword + อารมณ์ภาพ (คลังภาพองค์กรค้นซ้ำได้)
M3-6 แยกตามชนิดไฟล์: ภาพถ่าย → WebP/AVIF · ไอคอน/โลโก้/เวกเตอร์ → SVG เท่านั้น · ทุกภาพมี alt ภาษาไทย · เก็บที่ path production
M3-7 เพดานขนาดไฟล์ — เช็กที่ต้นทางด้วยคำสั่งจริง (ls -la / du แปะผลทุกไฟล์):
     hero ≤300KB · ภาพเนื้อหา ≤150KB · วิดีโอพื้นหลัง ≤2MB — เกิน = ยังไม่ผ่านเฟสนี้ ต้องบีบ/เปลี่ยนก่อน
เสริม: ภาพเก่าไม่คมชัด → Topaz รีทัชเข้า theme (จด log การเรียก API จริง) ·
อินโฟกราฟิก/ไดอะแกรมที่เจ้าของ confirm ไว้จากเฟส 4 → ลงมือทำใหม่ตาม Design System ที่นี่ (ดูง่าย ภาษา user)

[ส่วน 4 · ชุดคำถามบังคับ — รอบเดียว แล้วหยุดรอ]
ส่งใบเสนอภาพครบทุก section (5 ช่องต่อภาพ + ลิงก์ stock กดได้ + ขนาดไฟล์) แล้วให้เจ้าของ:
1. เลือกภาพทุกตำแหน่ง (เคาะรหัสภาพ)
2. อนุมัติ/ไม่อนุมัติ ภาพชั้น 2 (AI สร้าง+กราฟิกตกแต่ง) รายภาพ
→ เจ้าของยังไม่เลือกครบ = เฟสไม่จบ ห้ามใช้ภาพชั่วคราวแทน

[ส่วน 5 · ตารางจบเฟส]
(ก) ของส่งมอบ: .work/asset-register.md ครบทุกภาพ + ไฟล์ภาพจริงที่ path production + ผลวัดขนาดทุกไฟล์ — พิสูจน์ ls/du + git ls-files
(ข) ตาราง comply M3-1..M3-7 + PRE-IMAGE GATE = 8 แถว + หลักฐาน
(ค) เลขจากเครื่อง: mw-page-check (ส่วนเพดานไฟล์) / flow_gate.py ถ้ามี · ไม่มี = ระบุ "เครื่องยังไม่คุม"
ปิดท้าย: จบเฟส 6 — รอพี่ตรวจ · ถ้าผ่าน พิมพ์ `Use Migrate 7` · ผมเดินต่อเองไม่ได้ (กุญแจอยู่ที่พี่)

[ข้อห้ามเฉพาะเฟสนี้]
- ห้ามออกแบบลูกเล่น (เฟส 7) ห้ามแตะโค้ดหน้า (เฟส 8)
- ห้ามใช้ภาพที่เจ้าของยังไม่เคาะ ใส่หน้าไปก่อน "เดี๋ยวค่อยเปลี่ยน" — นี่คือการข้ามขั้น
```
