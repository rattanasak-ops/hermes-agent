# Use Migrate 1 — ยืนยันเมนูเก่ากับเจ้าของ + จองเมนู (สถานี M0)

> จุดเริ่มของ "1 เมนู" · ห้ามเดาว่าเมนูเก่าคืออะไร — เจ้าของต้องเห็นของจริงแล้วยืนยันก่อน

## Prompt

```text
Use Migrate 1

อ่านสัญญากลาง use-migrate-phase-contract.md ก่อน แล้วทำตามโครง 5 ส่วน

[ส่วน 1 · ด่านเข้า — รันจริง แปะผล]
1. .work/profile.yaml มีจริง + เจ้าของเป็นคนล็อก (git log author) — ไม่มี = MIGRATE_BLOCKED: ต้องทำ Use Migrate 0 ก่อน
2. จองเมนูใน .work/menu-queue.md ผ่าน branch กลาง work-locks:
   git pull --rebase ก่อนจอง · จอง = เพิ่มบรรทัดตัวเอง ห้ามแตะบรรทัดคนอื่น · push สำเร็จคนแรก = ได้ล็อก
   แพ้ = เห็นเจ้าของเดิม ห้ามแก้ทับ · ล็อกเมนูไม่ได้ = หยุดทั้งงาน ถามเจ้าของ (กฎหยุดระดับ 2)
3. อ่าน Token Design System ของโปรเจกต์ (ตาม ds_version ใน profile) — อ่านไม่ได้ = BLOCKED รายงาน
4. ตรวจ Header/Footer/Element ว่าเป็นโปรเจกต์ที่จองจริง (กันทำผิดโปรเจกต์ — เคยเกิด)
- ประกาศสถานีทุกคำตอบ: [Migrate เฟส 1/13 · สถานี M0 · เมนู: <ชื่อ> · โปรเจกต์: <ชื่อ>]

[เนื้องาน M0 — ครบ 8 ข้อเดิม ไม่ตัดทอน]
M0-1 หา URL หน้าเมนูเก่าจริงจากไฟล์ที่แคปมา (harvest/HTML) — ห้ามเดา/ประกอบ URL เอง
M0-2 ส่งลิงก์กดได้ให้เจ้าของ + แสดงหน้าย่อยทั้งหมดของเมนูนั้น (ตามรหัสหน้าจริง)
M0-3 เจ้าของกดดูของจริง + ยืนยันว่าเมนูนี้คืออะไร มีอะไร → รอเจ้าของตอบ (ห้ามเดินต่อก่อนได้คำตอบ)
M0-4 เมนูเก่าเป็นลิงก์เปล่า/ไม่มีสาระ/กำกวม → ห้ามสร้างเอง ต้องถามเจ้าของว่าเมนูใหม่ควรมีอะไร
      + เสนอจากการวิเคราะห์ของเก่า: ควรมี Infographic/Diagram ไหม (ไม่มีก็บอกตรง ๆ ว่าไม่มี)
M0-5 เก็บคำตอบเจ้าของเป็นไฟล์ .work/menu-cards/<เมนู>.confirm.md
M0-6 ไม่มีไฟล์ confirm นี้ = เข้าเฟสสร้างหน้า (Use Migrate 8) ไม่ได้ — จดกติกานี้ลงบัตรเมนู
M0-7 จดไว้ในบัตรเมนู: ภาพเทียบก่อน-หลังตอนส่ง ต้องใช้ภาพหน้าเมนูเก่านั้นจริง ไม่ใช่หน้าแรกเว็บ
M0-8 เสนอคำค้น SEO/AI Search ของหน้านี้ (ถอดจากเนื้อหาเก่า+โจทย์) ให้เจ้าของ confirm
      เพื่อใส่ในโครงสร้างหน้า รองรับทั้ง SEO และ AI Search

[ส่วน 4 · ชุดคำถามบังคับ — ถามรอบเดียวพร้อมลิงก์ของจริง แล้วหยุดรอ]
ส่งพร้อมกัน: ลิงก์เมนูเก่า (กดได้) + รายชื่อหน้าย่อย + ข้อสังเกตจุดอ่อนที่เห็น แล้วถาม:
1. ยืนยันว่าเมนูนี้คือเมนูที่จะทำ? หน้าย่อยครบ/ขาดอะไร?
2. เว็บเก่าเมนูนี้ พี่ "ไม่ชอบอะไร · ขาดอะไร · อยากได้อะไรใหม่"? (3 คำถามชุดเดิมของ flow)
3. คำค้น SEO/AI Search ที่ผมเสนอ — เอาชุดไหน ตัด/เพิ่มคำไหน?
4. คำถามที่รู้ล่วงหน้าของเฟสถัด ๆ ไป (ลดรอบรอ): เมนูนี้จะใช้ไอคอน/เวกเตอร์ไหม · มีตัวอย่าง/benchmark จะส่งให้ดูไหม (มี = เฟส 2 จะเปิดด่านรับตัวอย่าง · ไม่มี = จด NO_INPUT)
→ ทุกคำตอบจดลง .work/menu-cards/<เมนู>.confirm.md · ห้ามตอบแทน ห้ามถือว่าเงียบ = ยินยอม

[ส่วน 5 · ตารางจบเฟส]
(ก) บัญชีของส่งมอบ — พิสูจน์ด้วย ls + git ls-files:
  แถวจองใน .work/menu-queue.md (push แล้ว) · .work/menu-cards/<เมนู>.confirm.md (มีคำตอบเจ้าของครบ)
(ข) ตาราง comply: ด่านเข้า 4 ข้อ + M0-1..M0-8 = 12 แถว + หลักฐานต่อข้อ
(ค) เลขจากเครื่อง: มี flow_gate.py = แนบผล status · ไม่มี = ระบุ "เครื่องยังไม่คุม" ตรง ๆ
ปิดท้ายด้วยประโยคตายตัว: จบเฟส 1 — รอพี่ตรวจ · ถ้าผ่าน พิมพ์ `Use Migrate 2` เพื่อไปต่อ · ผมเดินต่อเองไม่ได้ (กุญแจอยู่ที่พี่)

[ข้อห้ามเฉพาะเฟสนี้]
- ห้ามเริ่มเก็บเว็บเก่า (งานเฟส 3) ห้ามเขียนโจทย์ (งานเฟส 4) ห้ามแตะโค้ด — เห็นว่าทำต่อได้ = จดลง "ของฝากเฟสถัดไป"
- เมนูที่เจ้าของยังไม่ยืนยัน = ยังไม่มีเมนู
```
