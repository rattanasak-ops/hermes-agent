# Use Migrate 11 — ด่านส่ง owner (สถานี S)

> ก่อนส่งหน้าให้เจ้าของดู ต้องผ่านเครื่องเช็กอัตโนมัติที่ fail ได้ — ไม่ใช่พึ่งความจำ AI · ตก 1 ข้อ = ห้ามส่ง

## Prompt

```text
Use Migrate 11

อ่านสัญญากลาง use-migrate-phase-contract.md ก่อน แล้วทำตามโครง 5 ส่วน

[ส่วน 1 · ด่านเข้า — รันจริง แปะผล]
1. .work/profile.yaml มีจริง — ไม่มี = MIGRATE_BLOCKED: ต้องทำ Use Migrate 0 ก่อน
2. ล็อกเมนูยังเป็นชื่อเรา + เฟส 10 ปิดจริง: `.work/deliverables/standards-comply-<เมนู>.md` มีครบ 9 เกต **และทุกเกตสถานะ "ผ่าน" พร้อมผลเครื่องแนบ** (grep ตรวจจริง — เจอเกต "ยังไม่รัน/ตก" แม้ข้อเดียว = BLOCKED กลับเฟส 10) · แค่ "มีเอกสารครบ" ไม่นับ
- ประกาศสถานี: [Migrate เฟส 11/13 · สถานี S · เมนู: <ชื่อ> · โปรเจกต์: <ชื่อ>]

[เนื้องาน]
S-1 รันเครื่องเช็กก่อนส่งของโปรเจกต์ (เช่น node scripts/check-page-deliverable.mjs "<url>") ต้อง exit 0 — แปะผลเต็ม
S-2 เครื่องตรวจครอบ: เมนูหลักครบ · มี <nav> · สีแบรนด์ถูกตาม DS · ไม่มีภาพคน AI/ภาพหลุดจากโปรเจกต์อื่น · desktop+mobile render · mobile มีปุ่มเมนู
S-3 ตก 1 ข้อ = ห้ามส่ง — แก้แล้วรันใหม่จนเขียว
S-4 ส่งหน้าเทียบ ก่อน↔หลัง: เก่า (ซ้าย · ภาพหน้าเมนูเก่าจริงจากเฟส 3 ไม่ใช่หน้าแรกเว็บ) ↔ ใหม่ (ขวา) · Desktop ก่อนแล้ว Mobile
S-5 มีแถบบอก "อยู่ขั้นไหน" + สรุปว่าต่างกันตรงไหน
S-6 ลิงก์จริงที่เจ้าของกดได้ + curl ตรวจตอบ 200 ก่อนส่ง · ห้ามส่งหน้าตัวใหม่เดี่ยว ๆ โดยไม่มีหน้าเทียบ
เปิดลิงก์ให้เจ้าของตามระบบ: mac = open · linux = xdg-open หรือส่งลิงก์กดได้

[ส่วน 4 · จุดถาม-ตอบบังคับ]
ส่งหน้าเทียบ + ลิงก์ แล้วรอเจ้าของดูจริง — เจ้าของตอบ "ผ่าน" = จดป้าย `PHASE11_APPROVED` + ชื่อ + วันที่ + สิ่งที่ดู ลง `.work/menu-cards/<เมนู>.approvals.md` · สั่งแก้ = กลับไปแก้ (เฟส 8/9 ตามเรื่อง) แล้วผ่านด่าน S ใหม่ทั้งรอบ

[ส่วน 5 · ตารางจบเฟส]
(ก) ของส่งมอบ: ผลเครื่องเช็ก exit 0 + หน้าเทียบก่อน-หลัง (desktop+mobile) + ลิงก์ที่ส่ง + คำตอบเจ้าของ
(ข) ตาราง comply S-1..S-6 = 6 แถว + หลักฐาน
(ค) เลขจากเครื่อง: ผล check-page-deliverable + curl 200 — แปะจริงทุกตัว
ปิดท้าย: จบเฟส 11 — รอพี่ตรวจ · ถ้าผ่าน พิมพ์ `Use Migrate 12` · ผมเดินต่อเองไม่ได้ (กุญแจอยู่ที่พี่)
```
