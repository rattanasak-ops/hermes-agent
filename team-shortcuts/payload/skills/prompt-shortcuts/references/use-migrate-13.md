# Use Migrate 13 — ปิดเมนู: รายงาน + เข้า DS + อัปเดตโรงงานกลาง (สถานี M8)

> เมนูปิดด้วยเครื่อง (menu-gate exit 0) + บัตรข้อเท็จจริง — ไม่มีบัตร = เมนูไม่ปิด · AI พูด "เสร็จ" เองไม่ได้

## Prompt

```text
Use Migrate 13

อ่านสัญญากลาง use-migrate-phase-contract.md ก่อน แล้วทำตามโครง 5 ส่วน

[ส่วน 1 · ด่านเข้า — รันจริง แปะผล]
1. .work/profile.yaml มีจริง — ไม่มี = MIGRATE_BLOCKED: ต้องทำ Use Migrate 0 ก่อน
2. ล็อกเมนูยังเป็นชื่อเรา + เฟส 12 ปิดแล้ว (แถว MIGRATION-STATUS ครบ) — ไม่มี = BLOCKED กลับเฟส 12
- ประกาศสถานี: [Migrate เฟส 13/13 · สถานี M8 · เมนู: <ชื่อ> · โปรเจกต์: <ชื่อ>]

[M8 ส่วน 1/3 — รายงานปิดเมนูให้เจ้าของ]
M8-1 รายงานภาษาคน + ลิงก์จริงกดได้ · ใช้แม่แบบรายงานมาตรฐาน close-report ทุกเมนู:
     หัวกระดาษ (โลโก้·โปรเจกต์·เมนู·วันที่) / เนื้อ (ภาพแคปฝังในรายงาน + ลิงก์กดได้ + ตารางมาตรฐาน + ปัญหาค้าง) / ท้ายกระดาษ (ผู้ทำ·ผู้ตรวจ·เวอร์ชัน)
M8-2 เทียบก่อน-หลัง: ภาพเก่าจากเฟส 3 (ซ้าย) ↔ หน้าใหม่ (ขวา) · Desktop ก่อนแล้ว Mobile · ฝังภาพในรายงาน
M8-3 CRUD ผ่าน/ไม่ผ่าน · ตารางมาตรฐานผ่านกี่ข้อ (เลขจากไฟล์ผลเฟส 10) · ปัญหาค้าง

[บัตรข้อเท็จจริง — บังคับ ไม่มี = เมนูไม่ปิด]
เขียน .work/deliverables/fact-sheets/<เมนู>.md: REQ→หน้าจอ→สิทธิ์→API→ตารางข้อมูล→เทสต์→หลักฐาน
+ ช่อง "ของใหม่เสนอเข้า DS": มีให้ระบุรายการ / ไม่มีให้เขียนคำว่า "ไม่มี" ชัด ๆ (ขออนุมัติรวมตอนจบโปรเจกต์)

[M8 ส่วน 2-3/3 — เข้า DS + โรงงานกลาง]
M8-4 จุดบันทึกผลเข้า DS (ไม่ใช่จุดขออนุมัติ): ของที่เจ้าของอนุมัติแล้วตั้งแต่เฟส 7 → บันทึกเข้า Design System ที่นี่ ·
     เจอของใหม่หลังเฟส 7 → จดท้ายรายงานรอเจ้าของยืนยัน ใช้ได้ในเมนูถัดไป (วงจรอนุมัติมาก่อนโค้ดเสมอ)
M8-5 ด่านปิดเมนูเชิงกล: รัน menu-gate (mw-menu-gate หรือ menu-gate.mjs ของโปรเจกต์) ต้อง exit 0 = CLOSED · เช็กหลักฐานจริงจากลิสต์แม่ (จำนวนข้อให้เครื่องนับ ห้ามพิมพ์เลขมือ)
M8-6 ข้อบังคับข้อใดแดง = เรียกเสร็จไม่ได้ — เครื่องดัก ไม่ใช่ดุลยพินิจ
M8-7 ยกด่าน+ลิสต์แม่เข้า Root Admin factory + เพิ่มใน ROOT-ADMIN-UPDATES.md (ให้เมนู/โปรเจกต์ถัดไปเกิดมาพร้อมของครบ)
+ อัปเดต RTM + ปลดล็อกเมนูใน .work/menu-queue.md (push) + เอกสารส่งมอบ: บัตรข้อเท็จจริงเข้าคิวประกอบเล่มตามงวดใน profile (ห้ามตั้งงวดเอง)

[Light Loop — เฉพาะกลุ่มหน้าโครงซ้ำ (เช่น OIT/ITA)]
ใช้ได้เมื่อหน้าแม่ของกลุ่มผ่านลูปเต็ม 13 เฟสแล้วเท่านั้น · หน้าลูกทุกหน้า: REQ ID + treatment + แหล่งข้อมูล + เครื่องตรวจ 100% ทุกหน้า ·
คนตรวจตา: หน้าแรกของทุกแบบ + สุ่ม 20%/กลุ่ม · ตัวอย่างตก 1 = ยกทั้งกลุ่มกลับตรวจเต็ม · หน้ามีฟอร์ม/สิทธิ์/ภาษา/ข้อมูลต่างชนิด = ออกจาก Light Loop ทันที

[ส่วน 4 · จุดถาม-ตอบบังคับ — เจ้าของรับรายงาน]
ส่ง close-report + บัตรข้อเท็จจริง + ผล menu-gate แล้วรอเจ้าของรับรายงาน (M8·1 ต้องรอเจ้าของ) — เจ้าของรับ = เมนูปิดจริง

[ส่วน 5 · ตารางจบเฟส]
(ก) ของส่งมอบ: close-report + fact-sheets/<เมนู>.md + ผล menu-gate exit 0 + แถวปลดล็อกใน menu-queue + ROOT-ADMIN-UPDATES (ถ้ามีของใหม่)
(ข) ตาราง comply M8-1..M8-7 + บัตรข้อเท็จจริง = 8 แถว + หลักฐาน
(ค) เลขจากเครื่อง (บังคับ): menu-gate exit code + จำนวนข้อลิสต์แม่จากเครื่องนับ
ปิดท้าย (เมนูจบ): จบเฟส 13 — เมนูนี้ปิดเมื่อพี่รับรายงาน · เมนูถัดไปเริ่มใหม่ที่ `Use Migrate 1` (โปรเจกต์เดิมไม่ต้องทำ Use Migrate 0 ซ้ำ) · ผมเริ่มเมนูใหม่เองไม่ได้ (กุญแจอยู่ที่พี่)
```
